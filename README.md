# Neusser Döner & Pizza – Website

Neue Website für Neusser Döner & Pizza (Neuss) mit dem neuen Logo.

- Farbpalette: „Mediterran frisch“ (Gelb `#F9C015`, Olivgrün `#4F7A2C`, Paprikarot `#B8321F`, Dunkelbraun `#3A1C05`, Creme `#FAF3E8`)
- Aufbau Startseite: Logo-Leiste → Angebote-Leiste → Header mit 4 Hauptgerichten im Kreis (Wechsel alle 3 Sekunden)

## Lokal ansehen

`index.html` im Browser öffnen – kein Build nötig.

## Noch offen

- Echte Speisekarte, Preise und Angebote (zurzeit Platzhalter)
- Fotos der 4 Hauptgerichte (freigestellt, PNG/WebP) für `assets/img/dishes/`
- Adresse, Telefon, Öffnungszeiten
